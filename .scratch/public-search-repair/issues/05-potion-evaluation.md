# 05: 让常见药水参与真实收益比较

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师可依据伤害、格挡、虚弱、力量和补能等公开效果，在当前战斗中比较使用与保留药水的收益。

**Blocked by:** [04：校正现有卡牌与常见状态估值](04-effect-coverage.md)

Status: ready-for-agent
Progress: resolved

- [x] 按实际出现的常见药水类别建立有明确边界的效果估值，覆盖至少直接伤害、格挡和虚弱三类；其他类别明确标注近似。
- [x] 原生对照验证药水效果、目标与库存消耗，不能把缺少 stats 的药水统一当作零效果。
- [x] 有能避免当前死亡或完成斩杀的用药回归，也有无即时收益时保留药水的反例；保留全部原生合法候选。
- [x] 补能产生的新组合在动态合法性未实现时明确截断，不能伪称已模拟后续。
- [x] 固定开发集独立开关此改动，报告用药、战斗耗血、胜率与时间成本，避免把使用次数增加直接当作质量改善。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。

## 验证记录

伤害／格挡／虚弱药水的原生效果、目标和库存已对照；有斩杀、生存、保留药水和补能边界回归。独立 potions 对照改变行动，但 8 次运行仍零胜，不宣称整体胜率提升。

详细命令、覆盖限制、逐配置结果和评审结论见[01–05 验证记录](../evidence/01-05.md)。
