# 战斗内价值函数的拟合探针（GAE 的前置）

- **时间**：2026-10-29
- **来源**：`.scratch/training-plan/issues/36-fight-fast-loop.md`（工单 36 阶段 01）；脚本 `.scratch/training-plan/scripts/fight_value_probe.py`、`fight_value_residual.py`；结果 `runs/rl-20261023/probe/fight-value/`
- **状态**：没有进入训练，退回战斗组的组基线（[ADR 0005](../adr/0005-fight-fast-loop.md)）

## 动机

战斗组的优势里 86% 的决策拿整段回报减组均值，只差 HP 的战斗推不动（工单 34）。设想是用一场战斗内的价值函数加 GAE，把信用分到每个决策上。用户 2026-10-29 定先离线拟合，门槛是留出战斗上的整体 R² ≥ 0.5、组内 R² ≥ 0.2，拟合不出就退回组基线。

## 做法

- 数据：explore-centered、explore-drift、explore-fix、explore-isolate 第 0 轮的战斗组，同一批 220 场战斗（fight-rl-12 第 4 轮采，T = 0.3），每场合计 32 条段，249,600 个有选择的决策。
- 目标：每个决策的剩余回报，即 −（这场战斗之后还要付的代价）/ 100，固定药价、`costs.cost` 的记账。
- 特征：fight-rl-12 第 3 轮冻结网络的全局 token 末层状态与 token 均值，512 维。
- 按入场存档分五份，留一份（44 场，44,495 个决策）。
- 组基线：这组段的平均总回报 + 这一段到此已发生的部分（决策时已知）。"组内 R²"是相对它的 R²。
- 两种拟合：直接拟合剩余回报（岭回归、两层 MLP）；只拟合相对组基线的残差（岭回归 λ 10–10⁴，带 dropout 的一层 MLP）。

## 结果

| 拟合 | 留出整体 R² | 留出组内 R² | 训练集组内 R² |
| --- | --- | --- | --- |
| 组基线本身 | 0.74 | 0 | — |
| 直接拟合，MLP（最好的一轮） | 0.52 | −0.83 | −0.35 |
| 直接拟合，MLP（第 25 轮） | 0.48 | −0.96 | 0.49 |
| 只拟合残差，岭回归 | — | 0.036–0.041 | 0.05 |
| 只拟合残差，MLP | — | 0.045–0.047 | 0.08–0.10 |

残差拟合按种类：普通 0.03、精英 0.04、Boss 0.04。残差占剩余回报总方差的 28%。

## 原因分析

- 一场战斗的难度主要由入场状态决定，组均值直接量到了它；在没见过的战斗上，冻结特征读出的难度不如组均值。
- 组均值之外的部分（同一入场之后各段的差别）大多来自之后的抽牌与敌人行动，在决策时不可知，状态只能解释其中不到 5%。
- 没做的：微调骨干的价值头，更多场次的战斗。这两项可能提高上限，但离 0.2 差一个数量级。

## 结论与后续

不接 GAE，快循环用现有的战斗组优势（组均值 + 分叉树）。

## 教训

- 组基线在同入场的组里已经把能从状态读出的大部分信息用掉了；价值函数要比的是"组均值 + 已发生的部分"，不是全体均值。
- 和[试错 38](38-group-value-model.md) 一样：先量相对组基线的残差能解释多少，再决定要不要做价值模型。
