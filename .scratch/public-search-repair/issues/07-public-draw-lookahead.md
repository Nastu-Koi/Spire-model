# 07: 从无序牌堆采样下一回合

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师在有界搜索中从公开无序牌堆采样可能的抽牌，评估已建模的下一回合行动，再执行一个真实动作并重新规划。

**Blocked by:** [06：搜索补能和费用变化后的新组合](06-dynamic-legality.md)

Status: ready-for-agent
Progress: resolved

- [x] 抽样保持卡牌多重集合，明确抽牌、弃牌与洗牌约束；不读取本局真实隐藏顺序或随机数状态。
- [x] 抽样随机源独立且可复现；对无序牌堆实体重新排列、增加隐藏字段或替换游戏 seed 后，相同公开历史的决策分布不变。
- [x] 样本数量与视野有上限，并可关闭做对照；先支持已验证牌型，无法建模的抽牌替换效果和敌方后续行为明确近似或截断。
- [x] 从生产规划器入口到原生单步执行的回归通过；模拟改变不得污染实际帧或其他分支。
- [x] 固定开发集报告与当回合搜索的配对结果和计算增量；没有收益证据时保持为可选实验。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
