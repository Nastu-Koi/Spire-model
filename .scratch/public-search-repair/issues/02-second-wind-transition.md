# 02: 修复 Second Wind 并统一效果转移边界

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师按实际可消耗的非攻击手牌估算 Second Wind 的格挡，并通过生产规划器的同一效果转移能力进行搜索与验证。

**Blocked by:** [01：固定种子对照与失败回放](01-reproducible-evaluation.md)

Status: ready-for-agent
Progress: resolved

- [x] 先将现有转移逻辑整理为规划器实际使用的可检查边界，保持已覆盖行为，再添加失败回归并修复；不另建测试专用模拟器。
- [x] 零张、一张、多张可消耗手牌及混合攻击牌的原生对照通过，正确处理正在打出的卡牌、消耗后手牌和格挡。
- [x] 捕获的实际获得 10 点格挡案例不再只估为 5 点；存在因消耗数量不同而改变动作选择的规划器入口回归。
- [x] 区分已建模、近似与未知效果；未知交互保留原生合法候选并显式截断。
- [x] 原生一步执行后重新观察，不把模拟预测写回真实对局；固定开发集报告修复前后结果及耗时，不要求由单卡修复保证整局胜利。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。

## 验证记录

效果转移提取前后，捕获局 96 帧动作及全部根评分一致；捕获错误、四类原生手牌消耗与生产规划器选择均有回归。开发集 second_wind 与 legacy 分开对照。
