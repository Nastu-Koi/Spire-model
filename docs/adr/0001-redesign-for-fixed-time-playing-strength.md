# 以固定训练时间内的游戏胜率驱动模型重设计

当前模型存在逐样本训练、细粒度输入编码和稠密关系偏置等实现开销；这些证据尚不能单独证明现有模型数学结构优劣。2026-09-22 的设计讨论决定允许全面修改模型结构，包括注意力公式、层调度、GRU 和参数规模，以固定训练时间内的游戏胜率为首要目标，而非单独最大化算子吞吐。

保留已有采集数据，允许重新初始化训练，不要求新模型加载旧 checkpoint。相比维持权重兼容，这会增加重新训练成本，但避免旧参数形状和结构限制候选设计。现有模型保留为比较基线。

新架构必须只使用行动前公开信息，保留完整合法动作集合、无序牌堆的重复数量与排列不变性，以及公开且有意义的顺序。输入表示可重做，但这些信息语义保持不变。

第一阶段保持现有 PPO 训练目标与奖励不变，允许重做批处理、并行环境和数据准备；发现的正确性问题仍应修复并单独记录。用户随后明确选择将 FFN 改为 SwiGLU，并使用 Muon，因此优化器不再以保留旧 AdamW 为约束。Muon 用于全局与局部 Transformer 的隐藏层 Linear 矩阵，embedding、Norm、bias、多选 GRU 和策略/价值头使用 AdamW；改变更新规则与等价内核替换分开记录。

GPU 总实验预算不设上限，但固定时间内的胜率仍是候选比较的首要目标，时间统计包含采样、更新、编译和评估。决策延迟暂不设硬性上限。优先用小模型获得快速调试反馈，小模型通过不代表最终规模已经选定；扩大模型需要后续学习效果与运行数据支持。

首个新架构基线采用小型纯 Full Attention，不预设必须混合 Full/Linear。极小模型用于数据流、梯度、排列不变性和批处理一致性检查，小型学习模型用于示范学习和游戏策略实验；混合及线性注意力保留为后续对照候选。这降低首轮调试复杂度，但不预先判断长序列下的最优结构。

示范训练集与验证集按整局和 seed 隔离；各候选使用相同且与训练隔离的评估 seed，覆盖全部五个角色。首要报告五角色平均胜率，同时报告最弱角色、失败率和统计不确定性。最终测试 seed 单独保留，不用于反复选型。示范 NLL、吞吐和显存仅作为诊断指标。

GRU 的设计职责是多选解码：维护一次多选过程的解码状态，而非提供整局游戏的历史记忆。后续评估其实现时，以多选正确性和批量执行能力为依据，不以缺少长期记忆为替换理由。

关系偏置按用户要求仅保留地图用途；不再以保持所有旧关系偏置为目标。效果程序仍保留结构、动态数值和实体绑定，缓存不依赖模型权重的解析结果并进行批量编码，而不是退化为内容 ID 对应的单一静态向量。

用户确认先使用 BF16 与 FP32 敏感计算；FP8 留作后续大 Linear/FFN 对照实验，不默认启用。

具体适用范围、首阶段实现与验收方案见 `docs/ATTENTION_REDESIGN.md`，用户已确认共同理解并授权开始实现。允许重设计不构成长时间训练的执行授权。
