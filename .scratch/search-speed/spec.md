# 搜索速度优化可行性诊断

Status: ready-for-agent
Progress: resolved

用户认为当前每 seed 约 16 分钟仍不可接受，要求使用 diagnosing-bugs 判断优化空间。本次是测量和方案诊断，不以微基准代替整局成功产出，也不直接更改生产预算或算法。

## 验收

- 从真实成功轨迹恢复固定战斗，核对输入哈希，重复比较仅一个预算变量。
- 分离真正搜索调用与计划／选择执行成本。
- 审计真实搜索树的完整历史重复与最终路线之外的计算量。
- 保留原始测量、诊断脚本、可失败的局部延迟＋结果门槛；说明局部结果与整局门槛的区别。
- 给出已证实、被削弱及仍待验证的假设与优化顺序。不宣称完成提速修复。

结果见 [诊断报告](evidence/diagnosis.md)。实验集中位于 experiments/，不进入生产入口。后续全局配置修改需要跨普通战斗、精英、Boss 和完整新种子验证。
