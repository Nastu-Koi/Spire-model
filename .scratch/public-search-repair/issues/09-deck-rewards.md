# 09: 按牌组边际收益选择奖励

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师根据现有牌组的需求、重复与协同选择卡牌或跳过奖励，而不是只比较单张面板分数。

**Blocked by:** [01：固定种子对照与失败回放](01-reproducible-evaluation.md)

Status: ready-for-agent
Progress: resolved

- [x] 覆盖伤害、防御、抽牌、成长等牌组缺口与重复牌的边际收益，使用公开牌组和资源。
- [x] 从真实奖励帧到原生选择的正反例通过：同一张牌在不同牌组中可能选择或跳过。
- [x] 升级与移除的公开选牌方向保持一致，特殊未知效果仍保留合法候选。
- [x] 冻结战斗策略，独立启用奖励策略做固定开发集对照；报告完整胜率和阶段指标，不以平均牌组大小单独验收。
- [x] 保留策略开关和测量依据，没有收益证据不默认宣称优化。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
