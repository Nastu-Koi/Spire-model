## 动机

整局只有一个 ±1，优势估计是旧 PPO 失败的原因（[12](12-outcome-ppo.md)）。想法是学一个直接回归通关概率的价值模型：给局外决策算时序差分优势（V = 2·p_win − 1），给战斗重打的战后第一帧定价（[20](20-joint-iteration-combat-replay.md)）。它在 a0 路线里是 AWR 的前提（[24](24-awr.md)），在联合迭代里是唯一的定价器。

## 做法

### v1（a0 工单 18）

- 网络：与策略同结构的 20M，输入局外决策帧，两个二分类头（通关、过本幕）。
- 数据：没有采样轮，用 300 局 greedy 评估对局（`runs/bootstrap-20261008/eval-a0/dev-v8`）。打出这些对局的检查点内部 `policy_version` 是 17，即旧结构 BC v8 第 17 轮，不是 GRPO v4。局外决策 27,342 个（每局约 91 个）；按 seed 留出 0.2：训练 226 个 seed／20,305 个决策，留出 74 个 seed／7,037 个决策。
- 设置：热启动全网络、只训头、只训顶部 4 层、低学习率、随机初始化、查找表冻结等，见结果表。
- 基线：常数、“幕 + 楼层”逻辑回归、加状态摘要的逻辑回归。

### v2：小配置、5,000 与一万局（joint-training 02）

- 起点策略 BC v12（`trained-a10/epoch-000012`）。采样 5,000 局（`round_seeds("critic", 0, 1000)`，`collect --workers 44`，战斗 0.3／局外 0.5），后加采 5,000 局（`collect/round-1`）。
- `configs/critic.json`：8 层 × 宽 128、4 头、FFN 352、局部 64／2 头／2 层，约 2.38M 参数；随机初始化，只沿用策略词表；初版 4 轮、Muon 1e-3、骨干 1e-4、查找表 1e-3、头 1e-3、预热 100。
- 留出 20%；学习曲线 1,000／2,000／全部训练局。门槛：通关解释方差 ≥ 0.16（一万局时为 ≥ 0.167）、过幕 ≥ 0.10 且高出基线 ≥ 0.080、校准、记忆看门。
- 为压住记忆，改为每局只取一部分决策：先按个数（thin8、thin4），后按比例（`--decision-share`）。
- 灵敏度探针 `scripts/critic_sensitivity.py`：把留出对局战后第一帧的 HP 改 −10／−5／+5、去掉一瓶药，看估值怎么变。

### 读不出 HP 的诊断（joint-training 04）

- 标签换成帧内的确定性量：头 0 `hp < max_hp / 2`，头 1 `hp < 40`。数据 `collect/round-0`，8×128 随机初始化。
- 四组：A（share05e6 的设置：5% 决策、6 轮、3e-4／3e-5）、B（全部决策 1 轮、同学习率）、C（B 加学习率全部 1e-3）、D（20M 策略检查点只训头的线性探针，50% 决策、1 轮、头 3e-3）。留出 AUC ≥ 0.95 视为读得出。

### 辅助目标（joint-training 05）

- 主干上第二个线性头回归辅助目标，损失 = 胜负两头交叉熵 + `aux_weight` × 辅助 MSE。目标：`hp_ratio`、`max_hp`（/100 截 1）、`gold`（/500 截 1）、`survive`（min(剩余层数, k)/k）、`hp_ahead`（k 层后 HP 比，死亡记 0）。`DATA_VERSION=critic-decisions-v2`。
- 数据 13,050 局（全是 v12），留出 2,641 局／200,435 个决策；8×128，`decision_share` 0.05，6 轮，学习率全部 1e-3，wd 0.1。四组 `none`／`frame`／`k3`／`k8`。
- 验收：门槛不放宽，加灵敏度（HP 单调的帧 ≥ 80%、斜率为正、一瓶药折合 3–30 HP）。

## 结果

### v1

留出解释方差（对 ±1 回报，常数基线为 0）：

| 模型 | 通关 EV | 过幕 EV |
| --- | --- | --- |
| 常数 | −0.004 | −0.004 |
| 逻辑回归：幕 + 楼层 | 0.059 | 0.058 |
| 逻辑回归：加状态摘要 | −0.043 | 0.068 |
| 热启动全网络，Muon 2e-4，4 轮 | −0.034 → −0.382 | 0.001 → −0.050 |
| 热启动只训头，6 轮 | 0.003（最高 0.006） | 0.001（最高 0.008） |
| 热启动只训顶部 4 层，3 轮 | 0.001 | −0.002 |
| 热启动全网络，Muon 5e-5，2 轮 | 0.007 | −0.001 |
| 随机初始化，3 轮 | −0.083 → −0.342 | −0.004 → −0.244 |
| 热启动、查找表冻结，3 轮 | 0.011 → −0.036 → −0.065 | 0.005 → −0.001 → −0.009 |
| 保存的 v1（查找表冻结，1 轮） | 0.007（AUC 0.57） | 0.003 |

- 记忆的形状（热启动全网络 4 轮）：“4,910 个留出决策预测 <0.1 而实际通关 21%，431 个预测 >0.9 而实际 32%”；“Ironclad 预测 0.41、实际 0.11；Defect 预测 0.12、实际 0.42”。全网络训练损失 1.17 → 0.64，留出 EV 同步变负。
- 不记忆的设置在每一幕、每个角色上都预测基础率附近的值，没学到幕的效应。
- 链路自检：标签换成确定性特征（本幕序号 ≥ 2），“1 轮后留出 EV 0.76、4 轮 0.996”。
- 留出噪声：300 局做 20 次按局划分，“幕 + 楼层”逻辑回归在 120／180／240 个训练局时 EV 0.065 ± 0.039、0.054 ± 0.025、−0.010 ± 0.264。
- 建议门槛：通关 EV ≥ 0.10 且 ≥ “幕 + 楼层”逻辑回归 + 0.05；按幕、按角色、按概率分段的校准限；记忆看门（训练损失下降不超过留出 Brier 改善的 3 倍）。写进 `critic/gate.py`。

## 原因分析

- 标签按局给。一局几十到九十个局外决策共用一个胜负，卡组与遗物足以认出是哪一局；模型最省力的降损失办法是记住训练对局。有效样本数是局数，不是决策数。
- 记忆的来源量过：同一种子内的随机性占通关方差的 84%（种子只解释 0.16，[21](21-seed-group-baseline.md)），每局的残差大且被整局的决策共享。
- 两难：高学习率（1e-3）一轮就读得出 HP（诊断 C），但在胜负标签上很快记住对局（v2 第一次学习曲线 EV −0.21）；低学习率（3e-5）不记对局，也读不出 HP（A、B）。v2 的 share05e6 对 HP 失明，拿它给重打定价，组内比较几乎只看“用没用药”。
- 辅助目标让主干读出了状态（frame 的 hp_ratio R² 0.89，HP 单调帧近 80%），但只把第 2 轮峰值抬约 0.01，第 3 轮后跌得一样快，没有推迟记忆；药水方向全反，去掉一瓶药估值反升。
- 冻结策略主干不行：20M 策略的全局标记里 HP 不是线性可读的（D）。
- v1 另有数据量问题：226 个训练局里“幕 + 楼层”逻辑回归也只有 0.059，留出 74 局上 0.1 以下的差别没有意义。

## 结论与后续

- 用户 2026-10-15 暂停 critic 线，改走组基线；2026-10-16 定删除。joint-training 09 删除 `main/critic/`、`configs/critic.json`、critic 续训与门槛、TD 优势、战斗重打与监测网页。v1 时期的代码在 `db6648d:critic/`。
- 取代它的是幕组：组续局的平均直接是状态价值的蒙特卡洛估计，不需要价值模型（[architecture 幕组的回报与优势](../architecture.md#幕组的回报与优势)、[learn 幕组的优势](../implementation/learn.md#幕组的优势)）。
- 恢复条件：用幕组给出的（幕开头状态，下一级组通关率）这类同一状态多条续局的平均作标签，噪声独立于单局，再训价值模型。

## 教训

- 判断标签能不能被记住，看状态预测不了的残差是否由同一局的多个决策共享；共享时有效样本数是局数。
- 先用确定性标签验证链路，把“编码读不出”和“优化没学到”分开。
- 记忆看门要比同单位的量（留出 log loss 对训练 log loss，不拿 Brier 比 log loss）；按个数截断会让短局偏重，要按比例抽。
- 依赖价值模型给小差别定价之前，先跑灵敏度探针；过不了就不启动依赖它的迭代。
- 辅助任务能让主干读出状态，但解决不了“胜负标签可被记住”。
