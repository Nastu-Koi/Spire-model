# 10: 让路线与补给决策兼顾成长和生存

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师基于公开地图、生命与资源选择路线，并在营火和商店完成对应的治疗、升级、购买或移除决策。

**Blocked by:** [01：固定种子对照与失败回放](01-reproducible-evaluation.md)

Status: ready-for-agent
Progress: pending

- [ ] 使用可见地图 DAG 和资源估算成长收益与死亡风险，不能读取未公开的遭遇、库存或奖励。
- [ ] 覆盖低生命优先补给与状态充足时选择成长机会的成对场景；原生流程可从走图继续到营火或商店完成选择。
- [ ] 分别验证治疗与升级、购买与离开、移除方向，保留完整原生合法候选。
- [ ] 冻结战斗与奖励策略，独立开关路线资源策略进行固定开发集对照。
- [ ] 报告阶段存活、资源和完整胜率及成本，无法从局部规则推断全局收益时明确保留实验状态。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
