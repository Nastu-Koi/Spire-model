# 13: 在保留种子上验收成功轨迹成本

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 用冻结配置在未参与调参的种子上运行完整采集与独立原生重放，给出是否达到平均五分钟一条成功轨迹的结论。

**Blocked by:** [12：选择并行度并验证安全缓存收益](12-throughput.md)

Status: ready-for-agent
Progress: pending

- [ ] 开始前固定验收种子、总预算、停止规则、策略与引擎版本；过程中不调参，也不剔除失败尝试。
- [ ] 至少 3 条完整成功轨迹通过全新原生进程重放、公开状态一致性、三幕 Boss 与最终胜利检查；原生错误或重放差异不得放宽验收。
- [ ] 实际总墙钟除以验收成功数不超过 300 秒，所有未完成尝试和初始化、验证、导出成本计入；不达标则本项保持未完成。
- [ ] 成功数据仍为公开信息 demonstration，失败和放弃轨迹保留但不混入训练。
- [ ] 报告成功数、样本量、不确定性、批次波动与错误分类；单次达标不宣称每个种子必过。
- [ ] 若未达标，给出可定位的差距和后续证据需求，不以功能测试通过或较高尝试吞吐关闭修复目标。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
