# 0004 局外对照改为多个重新播种的未来与全臂目标

- 日期：2026-10-25
- 状态：已废弃（2026-10-28 代码删除，见 [trials 43](../trials/43-prune-iterate-options.md)；原为已接受，实现中（本地工单 `.scratch/training-plan/` 22）；修订 [ADR 0003](0003-choice-pairs.md) 的"分枝"与"样本与优势"两条）

## 背景

ADR 0003 的局外对照在第七段跑了两轮（工单 19）：

- **训练内学会了，训练外不动**。第 2 轮自己的 2,505 个点上，策略对各分枝的期望优势从 0.088 升到 0.109；工单 18 探针的固定检查集上，分开的点的软胜率 0.5902、0.5899、0.5895，没有变化。用户在第 3 轮停掉了这一路。
- **标签掺着预知**。各臂从同一份存档续打，随机数状态相同，原选那条与段自己走的是同一个未来。标签回答的是"在这一个未来里哪个候选更好"，策略看不到这部分（工单 20）。
- **比值目标不适合被强制的臂**。这些臂的概率常近 0，温度 0.5 下一遍里对数概率漂得快，这一路的裁剪比例约 51%，第 2 轮有 411 个样本比值超过 10，最大到 e²⁰ 的上限。
- **引擎可以在点上换未来**。游戏的随机流可以就地载入（`Rng.LoadFromSerializable`），隔离副本加了 `reseed` 命令：公开状态与点上的帧不变，之后的随机结果换成由新种子派生的。冒烟：同一种子播两次之后逐帧相同；不播种时与主仓库引擎同一串动作逐帧相同（工单 20）。

## 选项

1. 维持 ADR 0003，只调份额。不解决预知和比值两个问题。
2. 多未来，目标不变：去掉预知；强制臂的裁剪照旧。
3. 多未来加全臂目标。
4. 全臂目标，不换未来：比值问题解决，预知仍在。

## 决定

选 3。

- **未来**：点上执行臂的候选之前 `reseed`，种子由轮的种子根、点与未来编号派生。同一点的各臂共用同一组 K 个种子，段自己的那个未来不在其中。K 由标签可重复性探针定（工单 20 第 2 项），`--choice-pair-futures K`，0 为 ADR 0003 的做法。
- **价值**：臂的价值 V̂_a 是 K 条续打回报的平均（±1，通关加剩血奖励），点内均值 V̄ 是各臂的平均，A_a = V̂_a − V̄；各臂相同的点剔除。
- **全臂目标**：点上量到的每个臂一个样本，损失 −A_a · log π_θ,T(a) 加 κ 倍 KL，不经比值、不裁剪（`--choice-pair-objective arms`）。
  - 同一状态上各臂相加是 −Σ_a A_a log π_θ,T(a)。Σ_a A_a = 0，所以它对臂 b 的 logit 的梯度是 A_b / T：每个量到的臂按自己的优势移动，与它现在的概率无关。
  - 它不是策略梯度 Σ_a π(a)·A_a·∇log π(a)：不按 π(a) 加权，低概率而好的臂也被推上来。约束靠 KL 与小学习率。
- **份额**：每个样本一遍约看一次。
- 其余同 ADR 0003：点的抽法、分枝的候选、重放、点后 greedy、幕组照旧。

## 后果

- **成本**：每点的续打数乘 K。按第七段的速度（约 1.3 万条约 32 分钟），保持一轮的时长就要把点数降到约 4,000 / K。
- **引擎**：Sts2Headless 加 `reseed` 命令；不播种时行为不变。重编会改变 DLL 哈希，锚点续跑的身份随之改变（BC 锚点流水线目前不用）。
- **残留的偏差**：
  - 预先排好的遭遇顺序、事件顺序、Boss、地图与共享遗物袋不随播种改变，K 个未来在这些上相同。它们对策略多半不公开，属于残留的预知。
  - 点后仍是 greedy 打法，比的是"按评估时的打法，这一步选哪个"。
  - 没量到的候选不进目标。
- **探针（2026-10-25，工单 22 阶段 03）**：300 个 A10 点、每臂 4 个未来，组内相关 −0.023，两半未来的最优候选一致 56%。候选之间的真实胜率差远小于换未来的噪声，单个点的标签几乎不可重复；背景里"标签掺着预知"不是训练外不动的主因，主因是噪声。所以 K 不按可靠度定：K 增大的降噪收益与多抽点相当。实现照本 ADR 保留（默认关），第八段是否使用由用户定。
- **风险**：全臂目标不随概率饱和，对少量点可能过推；第 1 轮后看这一路的 KL 与固定检查集，过高就降份额。
