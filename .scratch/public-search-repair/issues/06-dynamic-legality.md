# 06: 搜索补能和费用变化后的新组合

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 假设分支改变能量或费用后，搜索能发现根节点时不可打的手牌，并只在真实执行时提交原生候选。

**Blocked by:** [04：校正现有卡牌与常见状态估值](04-effect-coverage.md)

Status: ready-for-agent
Progress: pending

- [ ] 模拟状态拥有当前手牌、资源和已知费用语义；每步重新计算已建模卡牌的假设合法动作，不仅过滤根候选。
- [ ] 补能后解锁高费攻击、费用变化、X 费和已消耗卡牌的正反例通过；不支持的费用或状态约束明确截断。
- [ ] 规划器入口能选择收益依赖新解锁动作的组合，原生顺序执行确认可行。
- [ ] 只有第一个根动作映射到原生候选；假设候选引用不得直接发送到真实引擎。
- [ ] 固定开发集对照报告新增组合带来的行为变化及计算成本，未知动作仍保留。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
