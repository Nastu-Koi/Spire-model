# 只取死亡段的回溯分叉

- **时间**：2026-10-23 – 10-26（第五段在用，第六段起关掉，10-26 改写）
- **来源**：`.scratch/training-plan/issues/13-fatal-fight-potions.md`（工单 13，做法与第五段的数字）、`15-a9-growth-bonus.md`（第六段取消）、`26-fight-branch-points.md`（工单 26，改写）
- **状态**：被取代。选段与选点的规则改写为现在的[回溯分叉](../architecture.md#战斗组采样)，重放与分枝的机制保留。

## 动机

战斗组的组均值只比较整段打法，一瓶药淹在一场几十个决策里；会死的战斗里该不该喝药，要在同一个状态上比。

## 做法

- 每轮从战斗组**死掉的段**里取至多 N 条（`--fight-hindsight 300`，整场没用药的先取），按原段的动作从入场存档重放到**第 1 回合、倒数第二回合、最后一回合**的第一个决策，只留能喝药的点。
- 每个点一组：每种能喝的药一条强制喝（探索步），两条对照照常由策略选，都抽到战斗结束；按战斗组的记账定价，作为战斗组那一类的第二路学。

## 结果

- 第五段（A6–A9，440 × 8 的战斗组）每轮回溯 2,400–3,300 段、4.5–6.4 万个决策，采样 67–100 秒，重放出错 0 条。
- 强制喝药的优势均值一直为正（各轮 +0.09 到 +0.17）；第一轮有优势的 730 个喝药决策均值 +0.144，其中 HP < 30% 的 234 个 +0.186。第 9–11 轮喝药臂比对照少死：普通 12–17 个百分点、精英 7–15、Boss 3–4。
- 第六段起与战斗组的用药探索一起关掉（用户 2026-10-24），之后到第八段都没开。

## 原因分析

- 分组内的比较是干净的（同一状态、不同动作），但点的分布由结局决定：只取死掉的段、按"最后一回合"选点，点集中在输局的最后时刻，正向的喝药优势里有一部分来自"这些点本来就是该喝的"。
- 只比喝药：出牌顺序、防御时机这些战斗内的选择不在比较里；开头的强制分叉（第一回合前两步）也覆盖不到中后段。

## 结论与后续

- 2026-10-26 改写（工单 26）：主干取战斗组的全部段（按种类 3:4:4，不论死活），点按帧上的信息选：第一个危急帧（喝药与对照）、第 2 回合起策略前两名最接近的决策（两个动作各强制两条）、随机一回合的第一个决策（四条照常选）。`fork_points`、`died_segments` 删除。

## 教训

- 选点用结局（死没死、哪一回合结束）时，组内比较仍成立，但学到的是"输局最后时刻"的分布；选点只用决策时能看到的东西。
