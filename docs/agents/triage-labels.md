# Triage labels

| Canonical role | 本地 Status 值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 缺少必要信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提及某个 triage 角色时，使用本表对应字符串。执行进度不替代 triage 标签。
