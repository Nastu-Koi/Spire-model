# 收敛为允许真实回溯的唯一搜索主线

2026-09-26，用户确认允许教师依据真实对局试走结果回溯，只将最终操作轨迹交给学生，并选择只保留一个生产搜索方案。为复用已有原生战斗求解与整局搜索能力、降低重复建模及多主线维护成本，合并以 CombatSolver 为默认战斗后端，迁移新实现中有价值的能力后退役被替代的实现和入口；历史证据保留。

本决策替代 [ADR 0002](0002-public-information-search-for-bootstrap.md) 中“启动示范教师必须仅使用行动前公开信息”的限制，不把回溯所得标签宣称为公开信息教师标签。用户随后确认唯一整局搜索采用 MCTS，CombatSolver 负责战斗；学生每步只输入当时公开观察和完整合法动作，以最终所选动作作标签，不接收后续轨迹或撤销分支。

合并保留现有未验证教师可见性的监督数据契约与独立原生重放，不将搜索示范当作 PPO on-policy 数据。先完成入口统一、替代实现清理及能力回归；平均五分钟产出成功轨迹的目标保留为后续独立优化验收，不以本次合并通过代替性能达标。
