# Domain docs

本仓库采用 single-context：根目录 `CONTEXT.md` 维护领域术语，`docs/adr/` 保存决策依据。

## 阅读规则

- 探索代码前读取 `CONTEXT.md`，并阅读与当前工作相关的 ADR。
- 文件缺失时继续工作；术语和决策在实际确定后按需补充。
- 规格、问题描述、假设和测试使用词汇表中的领域术语。
- 与现有 ADR 冲突时明确指出冲突及重新讨论的理由。

## 维护位置

- 功能目标、验收条件和任务进度：`.scratch/<feature>/`。
- 当前使用方式和已知限制：相应 README 或使用文档。
- 历史搜索实验：`docs/archive/search/`，注明版本、条件和限制，避免被误当作当前能力。
- 同一内容只保留一个维护位置，其他文档使用链接引用。
