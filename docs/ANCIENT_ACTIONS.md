# 开局、远古之民与结局动作核对表

状态：**固定版本静态核对稿，运行验收与人工审核待完成。** 返回 [动作总表](ACTION_CATALOG.md)；普通问号事件见 [EVENT_ACTIONS.md](EVENT_ACTIONS.md)。

本表按本机 `v0.111.0 / 41cef1ea` 的 8 个 `AncientEventModel` 类型拆分，列出 **102 个静态遗物选项族**（涅奥 30、达弗 12、其余各 10），包含联机限定条目并明确排除于单人候选。静态池不等于每局可选列表；相同遗物类型的角色绑定、预先配置内容和实例差异仍须保留。另列 `TheArchitect` 结局事件，它不属于这 8 个遗物提供者。版本哈希与证据路径见动作总表。

所有父选择使用 `CHOOSE_EVENT_OPTION(event_ref,stage,option_ref)`，只枚举已经抽出、当前展示、未锁定的选项；对话唯一继续自动推进。不能让模型选古神的整个备选池，也不能额外增加通用“拒绝全部”。获得遗物后，按真实 `AfterObtained` 进入公共子会话，完成后恢复古神事件。

表中效果为本地中文表的展示模板；数值、绑定角色和牌名由当前实例填充，不靠 Python 重算。无额外拾取选择不代表该遗物后续战斗永远不会产生子选择。恰选 N 的不足处理使用原 CardSelectCmd 语义；没有依据不新增 SKIP／CANCEL。

| 核对号 | 当前阶段 | 合法动作／推进规则 |

## 4. 本表特有的验收点

- [ ] 102 个静态族与固定 DLL 的 8 位远古之民声明一致；每局只暴露实际选出的子集。
- [ ] Neow 的互斥组合、解锁状态与联机限定不会产生额外候选。
- [ ] Orobas 第三组选项都不可用时，锁定占位不成为可点击动作。
