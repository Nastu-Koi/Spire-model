# 使用公开信息搜索教师生成强化学习启动示范

> 2026-09-26：教师仅限公开信息的约束已由 [ADR 0003](0003-unify-backtracking-search.md) 替代。下文保留当时的决策和实验背景；相关历史实现与证据不因此改写。

2026-09-26 的设计讨论确定：搜索器用于生成神经网络进入强化学习流程前的启动示范数据，目标覆盖整局决策，而非求解固定种子的通关行动序列。算法尚未确定，不预设必须使用 MCTS。

教师选择动作时只能依据玩家行动前的公开信息；仅清理最终网络输入不足以满足这一要求。读取真实隐藏状态，或通过反复试走同一种子获知真实未来再生成标签，会使教师决策依赖学生不可获得的信息，因此不能作为满足本目标的教师。可以模拟可能的未来，但模拟与决策不得利用本局真实隐藏信息。

这项边界限制了现有固定种子搜索器的直接复用，需要进一步确认隐藏状态采样和战斗教师的能力。具体搜索方法、训练标签、计算预算及验收标准仍待讨论；本次决定不构成开始实现或长时间训练的授权。

后续讨论确认一条数据指包含全部决策的整局轨迹，当前优先产出成功轨迹。性能目标是在本机允许使用全部线程的条件下，平均每五分钟产出一条成功轨迹，失败尝试的成本也计入；这不是每个种子五分钟内必定通关的保证。与直接强化学习的收益比较暂缓，失败轨迹是否用于训练仍待定。

用户进一步确认允许模拟分支回溯，限制的是教师利用本局真实隐藏未来，而不是树搜索的撤销、重试或回传。多样本 rollout 尚未获选为首个实现方案；其与现有搜索相比的计算成本受到质疑，需要先明确性能方案。

第一阶段确定为铁甲战士 A0。允许有限深度搜索，并用规则或模型近似评估叶节点，以减少模拟成本；评估器的具体实现尚未选择。近似估值不能替代成功证据，最终交付轨迹仍须实际完成通关。

用户随后选择先用规则评估器，并允许根据当前公开状态提前放弃低希望对局，转向新种子；所有失败和放弃的耗时仍计入产出成本。失败轨迹保留，暂不用于训练。用户已确认共同理解并授权开始实现。

首个实现采用公开手牌的有限深度束搜索和公开地图规则评估，不调用未经信息边界审计的 CombatSolver。由于现有协议将效果标为 opaque、缺少可信的隐状态采样，搜索在抽牌、未知效果和回合结束处截断并估值，然后执行一个原生动作、根据新公开观察重新规划。该实现暂不跨未知未来搜索；它不是已经完成的 POMCP/信息集 MCTS，也不把近似战斗计算当作原生模拟。这项切分使信息边界可测试，但能否达到胜率及产出目标仍需真实游戏验证。
