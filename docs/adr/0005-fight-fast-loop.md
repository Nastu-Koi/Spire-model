# 0005 局外冻结、战斗单独快速迭代

- 日期：2026-10-29
- 状态：试行中（本地工单 `.scratch/training-plan/issues/36-fight-fast-loop.md`）

## 背景

[ADR 0001](0001-separate-combat-training.md) 之后，战斗组强化学习让 dev 从 BC 的 246 涨到 308，后来 A0 到约 420，然后停住：

- 第十八段（战斗组 1,000 场、一半人类入场池）两轮里，一半以上的战斗改了打法，平均掉血却不变（工单 34）。
- 战斗组的优势里，86% 的决策拿的是整段回报减组均值。只有死局推得动；只差 HP 的战斗，原样学、只学分叉点、优势取反三种都推不动。
- 局外的组内信号测不出来（[trials 42](../trials/42-act-values.md)），一轮的采样时间却有大头花在幕组上；局外为了补偿弱的战斗，比人类保守（工单 33）。
- 现行步长（BC 的 0.1 倍学习率、κ = 0.1、一遍）是为整局 ±1 的稀疏信号定的，战斗的信号密得多。

## 选项

1. 维持现行的幕组 + 战斗组同批训练。
2. 局外冻结，只训战斗：组基线（GRPO），更大的步长、可多遍。
3. 同 2，另加一场战斗内的价值函数，用 GAE 给逐决策的优势。

## 决定

先做 2，同时离线测 3 的可行性（价值函数对剩余回报的组内 R²，门槛整体 ≥ 0.5、组内 ≥ 0.2，用户 2026-10-29 定）；过门槛再接 3，不过就留在 2。

2026-10-29 的探针不过门槛（相对组基线的组内 R² 0.04–0.05，[trials 44](../trials/44-fight-value-probe.md)），所以只做 2。

- 局外：幕组各波的优势取 0，只留对起点的 KL（`--freeze-outside`），参考固定为起点。
- 战斗：不加 KL（`--fight-kl 0`），步长由扫描定（学习率为 BC 的 0.3／1 倍，一遍或两遍）。
- 奖励：只留 HP、最大生命、固定药价与死亡；成长奖励、拟合药价之后逐项加回，每项都用人类基准配对验证。
- 主指标：人类 A10 战斗基准；整局 A9 每隔几轮评一次，只用来看局外有没有被带坏。

## 后果

- 推翻"BC 之后学习率取 BC 的十分之一"（[trials 25](../trials/25-full-lr-grpo.md)）这一条，但只对战斗、只在扫描验证之后。
- 局外暂时不学；战斗变强之后再用最简单的幕组 GRPO 重新训局外。
- 选项 3 没有做：探针不过门槛，不引入价值估计。
