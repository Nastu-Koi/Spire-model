# 01: 固定种子对照与失败回放

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 从真实采集入口重复运行指定种子，保留动作与公开状态证据，生成可归因的质量和耗时对照报告。

**Blocked by:** None (can start immediately)

Status: ready-for-agent
Progress: resolved

- [x] 接受显式种子清单、策略配置和独立模拟采样随机源；实际游戏 seed 不进入教师输入。
- [x] 分离开发集和保留验收集；记录版本、配置、预算与停止规则，禁止运行后挑选成功样本重算成本。
- [x] 重复运行已捕获的失败种子并比较动作语义及公开状态；稳定复现或明确标注引擎非确定性。
- [x] 提供真实前后公开状态的局部效果对照和可重复命令，不依赖私有函数追踪或临时目录中的唯一证据。
- [x] 分别计数胜利、战败、放弃、预算停止、原生错误、协议错误和重放拒绝；计时包含初始化、未完成尝试、验证与导出。
- [x] 保留现有独立重放与三幕 Boss 验收，零成功时平均成功成本为空值；采集流程回归通过。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。

## 验证记录

固定 manifest 的 40 次开发对照重复稳定；分类错误为零，极短预算、独立重放拒绝和原生／协议错误分类由入口测试覆盖。跨帧敌人身份不明确时保留不可比较标记。

详细命令、覆盖限制、逐配置结果和评审结论见[01–05 验证记录](../evidence/01-05.md)。
