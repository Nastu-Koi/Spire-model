- [x] 形成当前覆盖清单；逐项检查 Damage、Repeat、Block、Energy、目标数量及条件参数的用途，不将面板变量统一解释为立即生效。
- [x] 原生对照覆盖力量、敏捷、虚弱、脆弱、易伤、多段攻击及自损的代表性组合，报告未支持的遗物或状态交互。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
