# 08: 验证成长与资源保留的跨回合价值

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 教师在有界未来样本中合理比较力量成长、有效抽牌、持续防御和资源保留，减少只追求当回合收益的选择。

**Blocked by:** [07：从无序牌堆采样下一回合](07-public-draw-lookahead.md)

Status: ready-for-agent
Progress: pending

- [ ] 给叶节点明确可解释的近似项及适用范围，不将任意分数标为通关概率。
- [ ] 提供成长牌值得投入和即将死亡时应优先生存的成对场景，检查可观察动作和后续效果，不绑定任意权重值。
- [ ] 变化仅限估值；固定搜索配置和开发种子，分别报告战斗耗血、Boss 通过率、完整胜率及耗时。
- [ ] 记录开发集调参范围和最终配置，保持保留验收集未参与调参。
- [ ] 仅在有收益证据时默认启用；无收益或证据不足时保留对照开关并明确报告，不将实验完成等同于目标完成。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
