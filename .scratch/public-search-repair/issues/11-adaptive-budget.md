# 11: 根据决策难度分配搜索预算

**Parent:** [公开信息搜索教师修复规格](../spec.md)。

**What to build:** 在冻结的质量基线上，简单决策少算，危险或难以区分的动作获得更多搜索预算，保持所有根动作可参与选择。

- [ ] 先记录上游各项的采用或不采用结论并冻结质量基线，避免预算实验同时改变策略语义。
- [ ] 预算只依据公开可见风险、候选数量或评分接近程度；每个根合法动作仍获得基础评估。
- [ ] 决策预算和整批预算均有明确边界，超预算及未完成尝试耗时被记录。
- [ ] 与固定预算做相同开发种子对照，报告成功产出、质量变化和规划耗时，不能只比较节点数。
- [ ] 保留回退配置；若质量收益不足以抵消成本，报告负结果而不默认启用。

所有实现沿用父规格的信息隔离、独立验收与失败证据保留要求。若触及原生适配器，执行相关协议回归及五角色各五局运行检查。
